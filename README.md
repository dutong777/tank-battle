# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas 实现的经典坦克大战（Battle City）复古街机游戏。**单个 `index.html` 文件**，无需任何依赖、无需构建，双击即可游玩。

## 玩法

- 操控黄色坦克，击毁不断来袭的敌方坦克，守住下方中央的老鹰基地。
- 敌人全部消灭即进入下一关，难度逐关提升；基地被击毁或生命耗尽则游戏结束。

## 操作

| 功能 | 按键 |
| --- | --- |
| 移动 | `方向键` / `WASD` |
| 射击 | `空格` |
| 暂停 | `P` |
| 静音 | `M` |
| 开始 / 重新开始 | `Enter` |

> 手机触屏端会自动显示虚拟方向键与开火按钮。

## 特性

- 🧱 **砖墙**：可被子弹击毁，可用于开路或建造掩体
- 🛡 **钢墙**：不可摧毁
- 🌊 **水域**：坦克无法通过，子弹可越过
- 🌿 **草丛**：可隐藏坦克
- 🦅 **基地（老鹰）**：被击毁即失败
- 🎖 4 种敌方坦克：基础 / 快速 / 强力 / 装甲（需多次命中）
- 🎁 随机掉落的道具：💣 炸弹（全屏消灭）、🛡 护盾、❤ 生命
- 🔊 基于 Web Audio API 的复古音效
- 📱 响应式布局，支持触屏操作

## 运行方式

直接用浏览器打开 `index.html` 即可；也可以在本地起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

或直接在线游玩：[GitHub Pages](https://<你的用户名>.github.io/tank-battle/)

## 技术说明

- 原生 JavaScript + Canvas 2D，无第三方库。
- 地图由 15×20 的网格构成（代码中用左右镜像保证对称）。
- 游戏主循环基于 `requestAnimationFrame`，按时间增量驱动，帧率稳定。
